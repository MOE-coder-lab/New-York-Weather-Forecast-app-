
# 🌍 ATMOSPHERE — Global Weather Intelligence

### Weather, understood. See beyond today's forecast.

ATMOSPHERE is an independent web development project designed to make weather information accessible, understandable and useful through a modern, responsive and interactive web application.

Built with HTML5, CSS3 and JavaScript, the application connects to Open-Meteo to retrieve genuine weather information for cities around the world.

## 🚀 Live Application

https://moe-coder-lab.github.io/New-York-Weather-Forecast-app-/

## 💻 Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Open-Meteo Weather API
- Open-Meteo Geocoding API
- GitHub Pages

## ✨ Key Features

### 1. Global Weather Search
Search for cities around the world and retrieve location-specific weather information.

### 2. Live Weather Conditions
Access current temperature, humidity, wind speed, precipitation, atmospheric pressure and UV index.

### 3. Five-Day Weather Forecast
Explore upcoming weather conditions, temperature ranges and precipitation probabilities.

### 4. Weather API Error Monitoring
Helps diagnose failed requests and monitor service availability.

### 5. Last Successful Update Time
Builds user confidence by displaying when the latest weather information was successfully retrieved.

### 6. Severe-Weather Warnings
Display severe-weather warnings when supported data is available. These are condition-based indicators, not official emergency alerts.

### 7. Historical Weather Information
Allow users to explore previous weather records and seasonal patterns using historical weather data.

### 8. Mobile Responsiveness Testing
Responsive layouts designed for mobile phones, tablets and desktop computers.

### 9. Accessibility Improvements
Keyboard-friendly controls, accessible labels, readable contrast and screen-reader status announcements.

### 10. Automated Testing
Built-in JavaScript tests demonstrate basic application functionality and quality checks.

## 📊 Weather Data

Weather information is provided by:

https://open-meteo.com/

Historical weather information:

https://open-meteo.com/en/docs/historical-weather-api

Geocoding services:

https://open-meteo.com/en/docs/geocoding-api

Weather forecasts are estimates and become less certain over longer forecast periods. Historical records are not future predictions.

## 🛠️ Installation and Usage

1. Clone or download this repository.
2. Open the `index.html` file in a browser.
3. Ensure an active internet connection is available.
4. Search for a city.
5. Explore live conditions, forecasts and historical records.
6. Use the Run Tests button to execute the built-in JavaScript checks.

No API key is required for the Open-Meteo endpoints used in this project. Provider usage limits and terms still apply.

## 🧪 Testing

The application includes basic automated JavaScript tests covering:

- Temperature conversion.
- Weather code identification.
- Unknown weather conditions.
- HTML escaping.
- Numeric formatting.

These tests are functional checks, not a replacement for comprehensive browser, API and end-to-end testing.

## 🔐 Reliability and Limitations

- Weather information requires an internet connection.
- API availability depends on the external provider.
- Forecast accuracy varies with location and forecast horizon.
- Condition-based warnings do not replace official weather alerts.
- Historical data availability depends on the provider.
- Automatic updates occur while the application is open and the browser is active.
